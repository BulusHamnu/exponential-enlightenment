# Overview

This is a personal portfolio website built for David Prorok to support his consulting sessions. It showcases his courses, the monthly Full Moon Program that guides people through meditation for inner peace and clarity, Boodi.AI, and a curated collection of resources to help individuals achieve enlightenment on their personal journey.

## Tech Stack

- HTML5 for page structure and design.
- CSS for page styling.
- JavaScript for mobileNavBar toggling, theme switching, scroll animation and contact form submission functionality.
